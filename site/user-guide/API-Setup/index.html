    API Signup and API Key Reference¶

    Name Description Hyperlink API Key
    GOV INFO Provides programmatic access to publications, metadata, collections, and other content from the U.S. Government Publishing Office. It can be used to search and retrieve federal documents and related package information. The API is useful for applications that need authoritative legislative, regulatory, and government-publication data. Gov Info API GOVINFO_API_KEY
    Google Geolocation Estimates a device's geographic location using nearby Wi-Fi access points and cellular network information. It is part of the Google Maps Platform and is useful when GPS data is unavailable or insufficient. Requests are authenticated through a Google Cloud API key. Google Geolocation API GOOGLE_MAPS_API_KEY
    Google Maps Provides Google Maps Platform capabilities for maps, directions, places, and map-related URLs and services. It can be used to build location-aware applications and launch Google Maps experiences from structured parameters. Access to billable Maps Platform services is managed through a Google Cloud project and API key. Google Maps API GOOGLE_MAPS_API_KEY
    Google Weather Provides weather information through Google Maps Platform weather services. It can be used to retrieve current conditions and forecast-related data for supported locations. Access is controlled through a Google Cloud project with the appropriate API enabled and an API key. Google Weather API GOOGLE_MAPS_API_KEY
    Google Geocoding Converts street addresses and place descriptions into geographic coordinates and can also perform reverse geocoding. It is commonly used to standardize locations for mapping, routing, and spatial analysis workflows. Access is managed through Google Maps Platform using a Google Cloud API key. Google Geocoding API GOOGLE_MAPS_API_KEY
    Gemini AI Provides access to Google's Gemini generative AI models for text, multimodal, and related AI workloads. It supports application development through the Gemini API and Google AI Studio tooling. Authentication is typically performed with a Gemini API key created in Google AI Studio. Gemini AI API GEMINI_API_KEY
    CDC Provides access to public health datasets published through CDC data portals, many of which use the Socrata Open Data API. Applications can query structured datasets for surveillance, epidemiology, and other public-health information. Authentication requirements vary by dataset, with Socrata application tokens commonly used for higher-rate access. CDC API SOCRATA_APP_TOKEN
    US Census API Provides programmatic access to U.S. Census Bureau demographic, economic, housing, and population datasets. It supports parameterized queries across many Census programs and geographic levels. An API key can be requested to support authenticated access and higher request volumes. Census API CENSUS_API_KEY
    NASA Firms Provides access to NASA FIRMS active fire and thermal anomaly data derived from satellite observations. It supports map and data services used for wildfire monitoring, emergency response, and environmental analysis. API access uses a FIRMS map key issued through the NASA FIRMS key-registration service. NASA Firms API NASA_FIRMS_MAP_KEY
    Wikipedia Provides programmatic access to Wikipedia and Wikimedia content through MediaWiki and Wikimedia APIs. It supports searching, reading, editing, metadata retrieval, and other wiki operations depending on the endpoint used. Many read operations do not require an API key, although authenticated workflows may use Wikimedia account credentials or tokens. Wikipedia API N/A (key not required for public read API)
    NASA Provides access to multiple NASA open-data APIs covering imagery, astronomy, Earth science, and mission-related datasets. The api.nasa.gov gateway hosts widely used services such as Astronomy Picture of the Day and Near Earth Object data. Most services use a NASA API key, with a limited DEMO_KEY option available for testing. NASA API NASA_API_KEY
    TheNewsAPI Provides programmatic access to current and historical news articles from multiple publishers and sources. It supports filtering by language, categories, dates, domains, and other query parameters. Access is authenticated with an API token issued through TheNewsAPI. TheNewsAPI THENEWSAPI_TOKEN
    News API Provides a REST API for searching and retrieving current news headlines and articles from many publishers. It supports source, category, keyword, language, and date-based filtering. Requests are authenticated with an API key created through NewsAPI. News API NEWS_API_KEY
    Grokipedia Uses the xAI account platform for credentials associated with xAI services. The xAI API provides programmatic access to Grok models and related capabilities rather than a separate public Grokipedia-specific key system. Authentication uses an xAI API key created in the xAI account console. Grokipedia API XAI_API_KEY
    Purple Air Provides access to PurpleAir air-quality sensor data and related environmental measurements. It can be used to retrieve sensor metadata, particulate-matter readings, and other fields for air-quality analysis. Requests use a PurpleAir API key created through the developer dashboard. Purpler Air API PURPLEAIR_API_KEY
    US Census Data Provides programmatic access to U.S. Census Bureau datasets covering population, housing, economic, and geographic information. It supports structured queries against numerous Census data products. An API key can be requested from the Census Bureau for authenticated access. Census API CENSUS_API_KEY
    The Air Now Provides access to AirNow air-quality observations, forecasts, and reporting-area information. It is commonly used for AQI monitoring and public environmental-health applications. Access requires an AirNow API key requested through the AirNow developer site. Air Now API AIRNOW_API_KEY
    Astronomy API Provides astronomy-focused data and visualization services for celestial bodies and observational calculations. It can support applications involving positions, rise and set times, star charts, and related astronomical information. Access is managed through credentials created with an AstronomyAPI account. Astronomy API ASTRONOMY_API_KEY
    Geoapify Provides geospatial APIs for geocoding, routing, maps, places, boundaries, and other location services. It is designed for web, mobile, GIS, and data-processing applications that require geographic enrichment. Requests are authenticated with an API key created in the Geoapify dashboard. Geoapify API GEOAPIFY_API_KEY
    Google Custom Search Engine Provides programmable search capabilities for querying a configured Google Programmable Search Engine. It can return web or image search results in JSON for integration into applications. API requests use a Google Cloud API key together with a Programmable Search Engine identifier. Google Custom Search Engine API GOOGLE_API_KEY
    IP Info Provides IP-address intelligence including geolocation, organization, ASN, privacy, and network-related attributes. It is useful for analytics, security, personalization, and network diagnostics. Authentication is performed with an IPinfo access token created through the IPinfo account portal. IP Info API IPINFO_TOKEN
    USGS Water Data API Provides access to U.S. Geological Survey water information and related hydrologic datasets. It supports programmatic retrieval of monitoring-location, time-series, and water-observation data. Authentication and access requirements depend on the specific Water Data API service and registered account. USGS API USGS_API_KEY
    Weather API Provides current weather, forecasts, historical weather, astronomy, air-quality, and related location-based weather data. It supports JSON and XML responses for application and analytics use cases. Requests are authenticated with a WeatherAPI.com API key. The Weather API WEATHERAPI_API_KEY
    Socrata Provides the Socrata Open Data API used by many government and public-sector data portals. It enables querying, filtering, aggregating, and retrieving tabular open datasets. Applications commonly use a Socrata application token for identification and improved rate limits. Socrata API SOCRATA_APP_TOKEN
    Open Weather Map Provides weather data including current conditions, forecasts, historical information, alerts, and geocoding-related services. It is widely used for location-based weather applications and data pipelines. Requests are authenticated with an OpenWeather API key. Open Weather API OPENWEATHER_API_KEY
    Opensky Provides access to aviation surveillance data from the OpenSky Network, including aircraft state vectors and flight-related information. It is used for research, aviation analytics, and air-traffic monitoring applications. Some endpoints permit anonymous access, while authenticated access uses OpenSky account credentials rather than a conventional API key. OpenSky API OPEN_SKY_USERNAME / OPEN_SKY_PASSWORD
    Aviation Stack Provides real-time and historical aviation data covering flights, airports, airlines, aircraft, and related operational information. It is designed for flight tracking, travel applications, and aviation analytics. Requests are authenticated with an Aviationstack access key. Aviation Stack API AVIATIONSTACK_API_KEY
    US Congress Provides official programmatic access to legislative data from the U.S. Congress. It includes bills, amendments, members, committees, nominations, treaties, and other congressional information. Access requires an API key issued through api.congress.gov. Congress API CONGRESS_API_KEY
    OpenAQ Provides open access to global air-quality measurements aggregated from government and research sources. It supports querying locations, sensors, parameters, measurements, and related environmental metadata. Current API access uses an OpenAQ API key. OpenAQ API OPENAQ_API_KEY
    Weather API Provides current weather, forecasts, historical weather, astronomy, air-quality, and related location-based weather data. It supports JSON and XML responses for application and analytics use cases. Requests are authenticated with a WeatherAPI.com API key. Weather API WEATHERAPI_API_KEY
    World News API Provides worldwide news search, article retrieval, topic monitoring, and related news-analysis capabilities. It supports filtering by language, country, source, date, text, and other criteria. Requests are authenticated using a World News API key. WorldNews API WORLD_NEWS_API_KEY
    Stadia Maps API Provides map tiles, geocoding, routing, static maps, and other location services. It can be used in web, mobile, and geospatial applications as an alternative map platform. Authentication is managed through API keys created in the Stadia Maps client dashboard. StadiaMaps API STADIA_MAPS_API_KEY
    EPA ECHO Web Services Provides programmatic access to EPA Enforcement and Compliance History Online data. It supports queries related to regulated facilities, inspections, violations, enforcement actions, and environmental compliance. Many EPA data services use a shared api.data.gov key for authenticated access. ECHO Web DATA_GOV_API_KEY
    EPA Facility Registry Service API Provides access to EPA Facility Registry Service information that integrates facility records across environmental programs. It can be used to retrieve facility identities, locations, program-system identifiers, and related registry data. Access commonly uses an api.data.gov API key. Facility Registry Service API DATA_GOV_API_KEY
    HHS Health Data Provides access to datasets published through HealthData.gov and related U.S. Department of Health and Human Services data services. It supports discovery and use of public health, healthcare, and administrative datasets. Authentication requirements depend on the specific dataset and underlying API platform. HealthData.gov API-dependent
    EPA I-Waste API Provides access to EPA industrial-waste-related data services exposed through EPA and api.data.gov infrastructure. It can support environmental analysis and applications that consume structured waste-related information. Access uses an api.data.gov API key when required by the service. I-Waste DATA_GOV_API_KEY
    EPA Envirofacts Provides access to EPA environmental datasets through the Envirofacts data services platform. It covers information from multiple EPA program systems and can be used for facility, chemical, emissions, and environmental-data queries. API access may use an api.data.gov key depending on the endpoint. Envirofacts DATA_GOV_API_KEY
    Grok XAI Provides programmatic access to xAI's Grok models and related AI services. It can be used for text generation, reasoning, tool use, and other supported xAI model capabilities. Authentication uses an API key created in the xAI account console. Xai API XAI_API_KEY
    Claude AI Provides programmatic access to Anthropic's Claude models for text generation, reasoning, tool use, and multimodal workflows. It is designed for integrating Claude into applications and automated systems. Authentication uses an Anthropic API key created through the Claude developer platform. Claude AI API ANTHROPIC_API_KEY
    ChromaDB Provides access to Chroma's vector database services for storing, indexing, and retrieving embeddings. It is commonly used to support semantic search, retrieval-augmented generation, and AI memory workflows. Chroma Cloud access uses credentials generated through the Chroma service. ChromaDB API CHROMA_API_KEY
    Huggingface Provides access to Hugging Face hosted models, datasets, inference services, repositories, and related machine-learning resources. It supports downloading artifacts and invoking hosted inference depending on the product being used. Authentication uses a Hugging Face access token created in account settings. Huggingface API HUGGINGFACE_API_TOKEN
    Jina AI Provides APIs for embeddings, reranking, document reading, search, and other AI retrieval capabilities. It is designed for semantic search, RAG pipelines, and multimodal information retrieval. Authentication uses a Jina AI API key created through the API dashboard. Jina AI API JINA_API_KEY
    Langsmith Provides observability, tracing, evaluation, and monitoring for LLM and agent applications. It integrates with LangChain and can also be used with other application stacks. Authentication uses a LangSmith API key created through the LangSmith account. Langsmith API LANGSMITH_API_KEY
    Llama Index Provides hosted services associated with LlamaIndex, including LlamaParse for document parsing and ingestion workflows. It is useful for extracting structured content from complex documents for downstream RAG and indexing. Authentication uses a LlamaIndex or LlamaParse API key created through the developer portal. Llama Index API LLAMA_CLOUD_API_KEY
    Mistral AI Provides programmatic access to Mistral AI language and multimodal models. It supports chat completion, embeddings, agents, and other model-serving capabilities exposed by the Mistral platform. Authentication uses a Mistral API key created in the Mistral console. Mistral AI API MISTRAL_API_KEY
    Pinecone Provides a managed vector database for storing and querying embeddings at scale. It is commonly used for semantic search, recommendation, retrieval-augmented generation, and agent memory. Authentication uses a Pinecone API key created through the Pinecone console or administration API. Pinecone API PINECONE_API_KEY
    Weaviate Provides a vector database and AI-native search platform for semantic, hybrid, and generative retrieval workflows. It can be deployed as a managed cloud service or self-hosted depending on the use case. Weaviate Cloud connections use an API key together with the cluster endpoint. Weaviate API WEAVIATE_API_KEY
