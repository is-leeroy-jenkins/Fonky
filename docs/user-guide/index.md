# User Guide Index

## Operational Sequence

1. pick the target domain,
2. choose direct invocation, domain grouping, or implementation access,
3. confirm dependencies and credentials,
4. execute the smallest test case,
5. expand into workflow composition,
6. persist or transform downstream as needed.
