    Composing Calls¶

    A typical application will normalize outputs at its own boundary rather than expecting every Fonky call to return the same shape.

    from fonky import fonky

location = fonky.geocode_location(
    address='Arlington, VA'
)

weather = fonky.fetch_google_weather_current(
    address='Arlington, VA',
    units_system='METRIC',
    language_code='en',
    time=10
)

paragraphs = fonky.scrape_paragraphs(
    uri='https://example.com'
)
